Cloud backup · Google Drive

How to get a Client ID (one time, free, about 10 minutes)
  1. On a computer, open console.cloud.google.com, sign in with any Google account and create a project named Bill Book.
  2. Open Google Drive API and tap Enable.
  3. Open Google Auth Platform → Get started. App name: Bill Book. Audience: External. Add your email as contact.
  4. Under Audience, tap Publish app (or add each Google account you'll use as a Test user).
  5. Under Clients → Create client → type Web application. In Authorized JavaScript origins add this app's address. Create.
  6. Copy the Client ID (ends with .apps.googleusercontent.com), paste it above, and tap Connect Google account.
